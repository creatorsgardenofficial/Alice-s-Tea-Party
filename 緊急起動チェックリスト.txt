==========================================
緊急：サーバー起動チェックリスト
==========================================

【重要】以下を順番に確認してください

□ 1. コマンドプロンプトを開く
   - Windowsキー → 「cmd」と入力 → Enter

□ 2. プロジェクトフォルダに移動
   cd "C:\Users\yamada\Documents\アリスのお茶会"

□ 3. Node.jsがインストールされているか確認
   node --version
   → バージョンが表示されればOK
   → 表示されない → Node.jsをインストール

□ 4. npmがインストールされているか確認
   npm --version
   → バージョンが表示されればOK

□ 5. 依存関係がインストールされているか確認
   dir node_modules
   → フォルダが存在すればOK
   → 存在しない → npm install を実行

□ 6. サーバーを起動
   npm run dev
   
□ 7. 以下のメッセージが表示されるか確認
   ▲ Next.js 14.x.x
   - Local:        http://localhost:XXXX
   - Ready in X.Xs
   
   → 「Ready」が表示されればサーバーは起動しています
   → エラーメッセージが表示されれば、その内容をメモしてください

□ 8. ブラウザでアクセス
   表示されたURL（例：http://localhost:3000）にアクセス

==========================================
確認すべきポイント：
==========================================

✓ コマンドプロンプトに「Ready」が表示されているか
✓ どのポートで起動しているか（3000? 3004?）
✓ エラーメッセージが表示されているか
✓ ブラウザのアドレスバーに正しいURLを入力しているか
