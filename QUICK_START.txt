===========================================
  アリスのお茶会 - クイックスタートガイド
===========================================

【重要】まず依存関係をインストールする必要があります！

方法1: バッチファイルを使用（最も簡単）
----------------------------------------
1. エクスプローラーでこのフォルダを開く
2. "install-deps.bat" をダブルクリック
3. インストールが完了するまで待つ（2-5分）
4. "start-server.bat" をダブルクリック
5. ブラウザで http://localhost:3000 を開く


方法2: コマンドプロンプトを使用
----------------------------------------
1. Windowsキーを押して「cmd」と入力、Enter
2. 以下のコマンドを順番に実行：

   cd "C:\Users\yamada\Documents\アリスのお茶会"
   npm install
   npm run dev

3. ブラウザで http://localhost:3000 を開く


【注意】
- Node.jsがインストールされていない場合は、先にインストールが必要です
- インストール確認：コマンドプロンプトで「node --version」を実行
- サーバーを停止するには、コマンドプロンプトで Ctrl+C を押す
